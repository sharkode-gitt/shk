## 5. Pegadinhas

- **Claude via Azure:** créditos Azure **não** pagam Claude no Foundry (cobrado via Marketplace). Houve caso de conta de US$17,6k por isso.
- **Claude via AWS:** créditos Activate valem para Claude no Bedrock (anúncio oficial).
- **Google Cloud trial:** pode não cobrir mais Gemini/Vertex para contas novas; confira antes de contar com ele.
- **Créditos de assinante (Claude Max/ChatGPT Pro):** são para a API, **não** para Claude Code ou Codex.
- **Nível grátis do Gemini:** seus dados podem ser usados para treinar; não envie nada sensível.
- Nunca cadastre cartão "só para testar" sem configurar **alerta de orçamento** na conta.
