# Emily Stories - 2D

2D cartoon characters (flat puppets with a thick outline) in a 3D world, made entirely from code. Start with the
`emily-stories-2d` skill (`.claude/skills/emily-stories-2d/SKILL.md` at the repo root) and `README.md`. Run every command
from this folder. The user writes Portuguese; video text and voices are English. Never put API keys in files or commits.
