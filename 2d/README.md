# Emily Stories - 2D

Short story videos (1080x1920, 9:16) with **flat 2D cartoon characters** (Remotion + ffmpeg). The engine comes from the
`videos-2d-curiosidades` skill: a story is only JSON (`stories/<slug>/bible.json` + `ep<N>.json`); no visual code to write.
Everything here is English (captions, voices, CTA). Run every command from this folder.

```
npm ci                                            # once (Remotion downloads its own Chrome the first time)
# ELEVENLABS_API_KEY goes in .env (git-ignored); load it in the shell before rendering
npm run ep -- emily-and-lokii 1 --stills=20,160   # check the look first (PNGs in out/, free)
npm run ep -- emily-and-lokii 1                   # voices + render -> out/emily-and-lokii-ep1.mp4
npm run ep -- emily-and-lokii 1 --range=0-300     # only a stretch
npm run studio                                    # Remotion Studio to preview live
```

- **Series**: `stories/emily-and-lokii/` - bible (Emily, Lokii, Bacon, Lexi with their ElevenLabs voice ids) and 4 episodes.
  Eps 1-3 end with the "PART N+1 / LIKE AND SUBSCRIBE" card (`nextTitle`); ep 4 ends with the A/B vote (`choice`).
- **Format of the JSON**: `docs/script-format.md`. `[brackets]` highlight a word in captions and titles.
- **Characters**: `bible.json` -> `characters.<id>` (skin, hair, hairStyle, top, pants, outfit, extras). Extras added for this series:
  `hat: crown | fedora | tophat | helmet`, `mask: skull`, `fur`, `bag`, `outfit: sweater`.
- **Backgrounds**: `escola` (hallway with lockers), `aula` (classroom), `parque`, plus the stock `porta`, `sala`, `corredor`,
  `carro`, `estrada`, `posto`, `loja`. New ones go in `src/lib/Background.tsx` or `src/lib/Scenery.tsx`.
- **Voices** are cached per text in `public/audio/cache` (re-render costs nothing; changing a voice spends credits again).
  Without a key it renders silent with estimated timing. SFX are generated by code (`scripts/sfx.ts`).
- Next episodes: `ANTHROPIC_API_KEY=... npx tsx scripts/gen.ts emily-and-lokii 5 "" "A: Yes, be his friend"` writes ep 5 from
  `memory.md` (that script writes Portuguese; edit its prompt in `scripts/gen.ts` to English before using it).
