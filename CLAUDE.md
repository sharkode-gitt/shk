# Emily Stories

Two separate projects: `3d/` (Roblox-style 3D characters, HyperFrames + Three.js) and `2d/` (flat 2D cartoon characters, Remotion).
Never mix them: work inside one folder, run its commands from there, and keep its assets, stories and output apart.
Skills: `emily-stories` (3D) and `emily-stories-2d` (2D). The user writes Portuguese; video text and voices are English.
Never put API keys in files or commits (`.env` is git-ignored).
